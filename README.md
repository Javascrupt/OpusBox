# OpusBox

A Windows GUI for downloading and syncing YouTube/YouTube Music playlists as Opus using yt-dlp, with resume protection, watchdog recovery, and MusicBrainz Picard integration.

## Features

- YouTube and YouTube Music playlist support
- Downloads audio as Opus
- Resume support using yt-dlp archives
- Automatic retry handling
- 3-minute stall watchdog
- Automatic yt-dlp restart after a stall
- Failed-track reporting
- MusicBrainz Picard integration
- Batch tagging for large playlists
- Sync behavior that skips previously downloaded tracks

## Requirements

- Windows
- PowerShell
- yt-dlp
- FFmpeg
- MusicBrainz Picard (optional)
