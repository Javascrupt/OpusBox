# OpusBox v0.1.0

Initial public build.

## Included

- YouTube / YouTube Music playlist support
- Opus download workflow
- yt-dlp archive-based resume support
- Retry handling and 20-second socket timeout
- 3-minute anti-stall watchdog
- Up to 3 automatic watchdog restarts
- Failed-track reporting
- Live completed-track progress
- MusicBrainz Picard integration
- Batch tagging support for large playlists
- Tag Existing Music workflow

## Windows Build

Attach `OpusBox-watchdog.exe` to the GitHub Release as the downloadable Windows binary.
